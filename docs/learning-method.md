# 6–9 周学习方法

本仓库不是论文或数据集镜像，而是一套以问题为中心的学习路径。每篇论文都从一个可回答、可证伪的问题开始，并要求把答案落到原文证据和一个可运行的最小实验上。

## 每篇论文的一周循环

1. **提出假设（第 1 天）**：在对应 `questions/q*.md` 的“我的初始理解”中，独立写出解释和你不确定的点。
2. **阅读并取证（第 2–3 天）**：通过 README 中固定的官方 abstract 版本获取论文 PDF；在问题文件的证据表记录章节、图表或公式，而不是只保存结论。
3. **压缩解释（第 4 天）**：阅读 `notes/<paper>/summary.md`，再用自己的话修订问题文件中的结论。
4. **最小验证（第 5 天）**：运行相应目录的代码，改变一个参数并记录预期、实际结果和可能混杂因素。
5. **主动回忆（第 6 天）**：完成 `checkpoints/` 的自测；错题回到论文原文补证据。
6. **间隔复盘（第 7 天）**：写下尚未理解的一个问题，并把本周结论与前一篇论文连接起来。

## 建议的 6 周节奏

| 周次 | 主题 | 可交付物 |
| --- | --- | --- |
| 1 | ResNet：优化与残差路径 | Q1 证据表、梯度实验记录、checkpoint 1 |
| 2 | Transformer：注意力与并行 | Q2 证据表、mask 实验记录、checkpoint 2 |
| 3 | DDPM：加噪与去噪 | Q3 证据表、采样实验记录、checkpoint 3 |
| 4 | 交叉比较 | 三种“捷径/路径”机制的对照笔记 |
| 5 | 复做与扰动 | 每个最小实验至少一个受控改动 |
| 6 | 综合输出 | 用自己的例子回答三个问题并标注证据 |

如有更多时间，把第 7–9 周用于重读原文、复现实验差异、阅读后续工作或实现一个小变体。不要把 smoke 输出当成学习结论：它只证明入口可离线运行，论证仍应来自论文证据和受控实验。
